# MY-WEBSITE-1

## 📚 Overview
An educational HTML project designed to explain **basic computer concepts** and **Microsoft Office fundamentals**.  
This project was created for **training purposes** and deployed via **GitHub Pages** and **Netlify**.

---

## 🛠️ Technologies Used
- HTML5  
- CSS3  
- Basic JavaScript (optional enhancements)  

---

## 🎯 Features
- Simple and clear structure for beginners.  
- Pages covering:
  - Computer basics (hardware & software).  
  - Microsoft Office (Word, Excel, PowerPoint).  
- Responsive design for desktop and mobile.  
- Easy deployment on GitHub and Netlify.
